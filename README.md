## 📌 Overview

Page Pulse is a full-stack web application that audits websites and generates detailed SEO and performance reports.

It helps users quickly inspect website metadata, page structure, images, links, loading performance, and SEO best practices.

---

## ✨ Features

- 🔍 Website SEO Audit
- 📈 SEO Score Calculation
- ⚡ Performance Metrics
- 🏷 Metadata Analysis
- 🖼 Image & ALT Text Detection
- 🔗 Link Analysis
- 📊 Interactive Charts
- 📜 Audit History
- 📄 PDF Report Export

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Ninaad25/page-pulse.git
```

### Install dependencies

Frontend

```bash
cd client
npm install
```

Backend

```bash
cd ../server
npm install
```

---

## ▶ Run the project

Backend

```bash
cd server
npm run dev
```

Frontend

```bash
cd client
npm run dev
```
